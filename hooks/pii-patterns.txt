# PII / sensitive-content patterns enforced by hooks/pre-commit.
#
# - One case-insensitive `grep -E` pattern per non-comment, non-blank line.
# - The hook matches against ADDED lines in the staged diff only.
# - Add a new pattern the moment you discover a new leak vector.
# - Keep patterns specific enough to avoid false positives, broad enough to
#   catch obvious variants (use \s* for optional spaces, \b for word boundaries).

#
# This tracked file holds only GENERIC patterns that identify no one.
# Literal names, case identifiers and client identifiers live in the
# gitignored hooks/pii-patterns.local.txt, which the hook and the full-tree
# scanner load too when it exists. Add specific leak vectors there.

# --- US Social Security number shape ---
